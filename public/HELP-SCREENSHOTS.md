# Help screenshots

Put these PNG screenshots directly in `public`. The guide loads them automatically; missing files show a pixel-bordered placeholder.

| Filename | What to capture |
| --- | --- |
| `help-paths.png` | Map with a cleared room, glowing exits, and a branch without an upward path. |
| `help-deck.png` | Open deck viewer showing cards, skills, and pagination. |
| `help-shop.png` | Shop with gold, healing, and elemental skill purchase options. |
| `help-rest.png` | Rest site with healing and attack-upgrade options. |
| `help-treasure.png` | Treasure room with the Claim 50 gold button. |

Elite and boss pages use text only and do not need screenshots.

Use landscape PNGs, ideally 960 x 540. Crop to the relevant UI and avoid unnecessary empty space. Images use contain sizing and pixelated rendering.
